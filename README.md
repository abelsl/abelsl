### 🍽️ GEBETA — Restaurant Management System

A full-stack restaurant management platform designed to digitize restaurant operations.

**Built with:** Next.js · TypeScript · React · Firebase/Firestore · Tailwind CSS

* Role-based access control for restaurant staff
* Digital menu management
* Online ordering
* Table management and reservations
* Order and invoice management
* Inventory management
* Staff communication
* Restaurant analytics
* Firebase Admin integration
* Authentication and authorization

The project was designed around real restaurant workflows rather than simply being a CRUD application.

---

### 📱 SMS Forward — Birr Payment Gateway

An Expo/React Native application designed to process payment notification SMS messages and forward structured transaction data to a backend.

**Built with:** Expo · TypeScript · React Native · Zustand · AsyncStorage · Firebase

The application can:

* Listen for incoming transaction SMS messages
* Parse payment information
* Extract transaction IDs, amounts, sender information and balances
* Forward structured transactions to a backend
* Queue failed requests for retry
* Import relevant historical SMS messages
* Communicate with a configurable API endpoint
